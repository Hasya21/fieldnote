# Resume-ready project description

**Consumer Insights Analytics Dashboard (Fieldnote)** — Independent full-stack portfolio project.

- Engineered an Angular 22 analytics workspace with TypeScript and SCSS, integrating REST APIs through typed services, reactive filters, protected lazy-loaded routes, and reusable chart and table components.
- Built an Express analytics API over 23,392 reproducible fictional sales records, implementing validated queries, paginated results, period comparisons, JWT authorization, and rate-limited authentication.
- Added 21 unit/API tests with Jest and Node's test runner, browser workflow checks, and a GitHub Actions pipeline that lints, tests, builds, and packages the application; applied OnPush rendering, debounced queries, and lazy chart loading.

These bullets describe repository implementation, not commercial employment, measured business impact, or a verified hosted deployment.
